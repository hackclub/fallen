Firmware is the code that brings your Tamagotchi to life. You write it in the Arduino IDE and upload it to the XIAO over USB-C.

## Follow the firmware tutorial

Head to the full [Firmware Setup Tutorial](https://fallout.hackclub.com/docs/guided-projects/tamagotchi-firmware) to program your board.

## Before you start

Your code needs to know which pins you wired things to. If you followed this guide, they are:

| Part       | Pin |
| ---------- | --- |
| Button 1   | D1  |
| Button 2   | D2  |
| Button 3   | D3  |
| Screen SDA | D4  |
| Screen SCL | D5  |

If you moved a wire to a different pin in the schematic, use that pin in your code instead.

## If you get stuck

- Flashing not working? Try a different USB-C cable (some only charge), a different port, or a different upload method.
- Ask in #fallen. Debugging is a normal part of making hardware!
